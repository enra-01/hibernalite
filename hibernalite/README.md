# HibernaLite 🚀
**Aplikasi Hibernasi & Pengoptimal RAM Khusus Realme Narzo 50A Prime (Android 12)**
*100% Bebas Iklan • Tanpa Pelacak • Tanpa Izin Internet • Super Ringan*

---

## 🌟 Fitur Utama
1. **100% Bebas Iklan & Aman**: Tidak memiliki izin akses `INTERNET` sama sekali, sehingga mustahil menampilkan iklan atau mengirim data keluar.
2. **Monitor RAM Real-Time**: Membaca sisa RAM, persentase penggunaan RAM, dan kapasitas total RAM (4 GB) Realme Narzo 50A Prime.
3. **Pembersih Cepat (Quick Clean)**: Membersihkan cache proses latar belakang dengan 1 kali klik.
4. **Hibernasi Otomatis (Accessibility Service)**: Mengotomatiskan penekanan tombol "Paksa Berhenti" (*Force Stop*) untuk aplikasi latar belakang yang dipilih.
5. **Daftar Pengecualian (Whitelist)**: Cukup hilangkan tanda centang pada aplikasi penting (seperti WhatsApp atau Alarm) agar tidak ikut ditutup.
6. **Proteksi Sistem**: Otomatis mengabaikan aplikasi bawaan sistem (*System UI, Phone, Settings, dll.*) agar perangkat tetap stabil.

## 📱 Cara Mengubah Menjadi File APK (Pilih Cara Termudah)

### **Cara 1: Menggunakan Android Studio (Sangat Disarankan untuk Emulator)**
1. Unduh dan buka **Android Studio** di komputer Anda.
2. Pilih menu **File** $\rightarrow$ **Open**, lalu arahkan ke folder ini:  
   `C:\Users\Pliz\.gemini\antigravity\scratch\hibernalite`
3. Tunggu proses *sync* selesai.
4. Untuk mencoba di emulator virtual:
   * Klik tombol **Play (Run 'app')** berwarna hijau di pojok kanan atas.
   * Pilih Android Virtual Device (AVD).
5. Untuk membuat file `.apk` siap pasang:
   * Buka menu **Build** $\rightarrow$ **Build Bundle(s) / APK(s)** $\rightarrow$ **Build APK(s)**.
   * File `.apk` akan siap di folder `app/build/outputs/apk/debug/app-debug.apk`.

---

### **Cara 2: Otomatis via GitHub (Tanpa Perlu Pasang Android Studio di PC)**
Di dalam folder ini sudah disertakan file `.github/workflows/build-apk.yml`:
1. Buat akun di [GitHub.com](https://github.com) (gratis).
2. Buat repository baru (bisa disetel *Private* agar kode Anda aman).
3. Upload seluruh folder `hibernalite` ini ke repositori Anda.
4. Buka tab **Actions** di GitHub, proses build APK akan otomatis berjalan ~1-2 menit.
5. Klik pada hasil build dan download file **`HibernaLite-APK`**.
6. File `.apk` siap langsung diinstal ke HP Anda atau emulator PC (BlueStacks / LDPlayer)!

---

## ⚙️ Cara Menjalankan di Ponsel / Emulator
1. Pasang (*install*) file APK hasil build.
2. Buka aplikasi **HibernaLite**.
3. Saat pertama kali menekan **"Hibernasi Aplikasi Terpilih"**, aplikasi akan meminta izin aksesibilitas.
4. Klik **"Buka Pengaturan"**, cari **HibernaLite**, lalu aktifkan.
5. Aplikasi siap digunakan kapan saja untuk melegakan RAM!
